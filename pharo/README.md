# Pharo Snapshot

This directory contains the current Pharo working image from the machine where
these dotfiles were exported.

Included:

- `Pharo.image`
- `Pharo.changes`
- `Pharo13.1-64bit-c4d03ec.sources`

Excluded on purpose:

- `pharo-local/`
- global identifier files under `~/.config/pharo/`
- template caches

The image is included as a practical snapshot, not as a clean reproducible
build artifact.
